# Baseline · 3D Campus Build

Interactive Three.js timeline of the hyperscale campus rising week by week.

## Run

```bash
make viz
# open http://localhost:8765
```

## Controls

- **Play / Pause** — auto-advance construction weeks
- **Scrubber** — jump to any week
- **Free cam / Auto orbit** — drag to explore, or let the camera orbit
- Structures tint by status: complete, in progress, slip risk, critical path
